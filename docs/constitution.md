# StudyForge AI — プロジェクト憲法

## プロジェクト概要

**プロジェクト名**: StudyForge AI

**一言説明**:
日本語IT学習者向けのAIフラッシュカード生成アプリ。

**詳細**:
ユーザーが技術記事、GitHub README、メモ、教材テキストを入力すると、AIが重要ポイントを抽出し、フラッシュカードと小テストを自動生成する。生成されたカードはユーザーが確認・編集してからデッキに保存し、繰り返し学習できる。

---

## ターゲットユーザー

- 日本語でITを学ぶエンジニア・学生
- Claude Code、Linux、Git、Supabase、n8n などの技術を体系的に学びたい人
- 技術記事を読んでも知識が定着しにくいと感じているセルフラーナー

---

## 開発原則

1. **学習体験を最優先にする**
   ユーザーが入力した教材から、学習しやすいフラッシュカードと小テストを生成することをすべての意思決定の起点とする。

2. **MVPは機能を絞る**
   最初のリリースはテキスト入力とURL入力に絞る。動くものを早く届け、フィードバックを得ることを優先する。

3. **後続フェーズに回す機能を明確にする**
   PDF取り込み、YouTube字幕取り込み、Ankiエクスポート、課金機能は Phase 2 以降とする。MVPに含めない。

4. **スマホファーストのUI**
   画面サイズに関わらず快適に使えるレスポンシブデザインを基本とする。タップ操作を考慮したUI設計を行う。

5. **日本語出力の品質を担保する**
   AIが生成するカードの表現は自然な日本語になるようプロンプトを設計する。機械的な直訳調にならないよう注意する。

6. **ユーザーが生成結果を確認・編集できる**
   AIの出力はそのままDBに保存せず、必ずユーザーが内容を確認し、編集・削除できるフローを設ける。

7. **学習データは正規化して保存する**
   データは `deck`（デッキ）、`card`（カード）、`quiz`（小テスト問題）、`review_log`（学習履歴）のように役割ごとにテーブルを分離する。

8. **デッキ販売を見据えた設計にする**
   将来的に Claude Code、Linux、Git、Supabase、n8n などの公式学習デッキを販売できるよう、デッキに `is_public` / `price` などの属性を持てる構造にする。ただし課金実装は MVP には含めない。

9. **APIキーと認証情報を保護する**
   すべてのシークレット（Anthropic APIキー、Supabase Service Role Key 等）は `.env.local` で管理し、フロントエンドに露出させない。AI生成処理は必ず Next.js API ルートに閉じ込める。

10. **実装前に仕様・設計・タスク分解を行う**
    新しい機能を実装する前に、必ず仕様（spec）→ 設計（plan）→ タスク分解（tasks）の順にドキュメントを作成・更新してから着手する。

## 品質基準

| 領域 | 基準 |
|------|------|
| 言語 | TypeScript を使い、`any` を避けて型安全に実装する |
| UI | shadcn/ui コンポーネントを使い、デザインの一貫性を保つ |
| アーキテクチャ | ビジネスロジックはコンポーネントから分離し、`lib/` や `services/` に置く |
| AI処理 | Anthropic API 呼び出しは Next.js の API Route (`app/api/`) にのみ記述する |
| DB設計 | Supabase のテーブル・カラム・RLS ポリシーを明示的に定義する |
| エラー処理 | エラー発生時はユーザーが理解できる日本語メッセージを表示する |
| スコープ | MVPに不要な機能は追加しない。シンプルさを優先する |

---

## フェーズ計画（概要）

| フェーズ | 内容 |
|----------|------|
| **MVP** | テキスト入力・URL入力 → AIカード生成 → 確認・編集 → デッキ保存 → フラッシュカード学習 |
| **Phase 2** | PDF取り込み、YouTube字幕取り込み、Ankiエクスポート |
| **Phase 3** | 課金・デッキ販売、公式学習デッキ提供 |
| **Phase 4** | スペーシング復習アルゴリズム（SM-2等）、学習統計ダッシュボード |

---

## 技術スタック（予定）

| レイヤー | 技術 |
|----------|------|
| フロントエンド | Next.js (App Router) + TypeScript |
| UI | shadcn/ui + Tailwind CSS |
| バックエンド | Next.js API Routes |
| AI | Anthropic Claude API (`claude-sonnet-4-6`) |
| DB / Auth | Supabase (PostgreSQL + Auth + Storage) |
| デプロイ | Vercel |
